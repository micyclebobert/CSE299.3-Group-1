# Sprint 5 Plan — SimQC

**Sprint goal:** Ship the browser-resident VS Code-style dark-mode UI shell: the dockable panel layout (Left Gate Palette, Main Qubit-Row Circuit Editor, Right Code/AI container, Bottom Inspector container), the pure canvas painting + drag-and-drop interaction layer, the undo/redo history, and the theme system — all running unmodified in bare Node.js for the pure parts, with **zero DOM leakage into `core/`/`circuit/`/`sim/`**.

This sprint is **UI only**. No changes to `core/`, `circuit/` (beyond what's already frozen), `sim/`, `gates/`, `measurement/`, `algorithms/`, `debugger/`, `inspector/`, or `ai/`. The engine remains untouched.

---

## Acceptance criteria

* `node --test` passes 100% from the repo root; Qiskit/NumPy cross-validation tests skip gracefully when unavailable.
* `test/canvas/`, `test/editor/`, `test/ui/`, `test/state/` mirrored test files added and passing.
* `Layout.js`, `Renderer.js`, `geom.js`, `theme.js` unit-tested in bare Node without DOM (no `window`/`document` references).
* `History.js` undo/redo round-trip verified over 100 random `Circuit` operations using `Circuit.isEqualTo`.
* Dark-mode theme constants live in `canvas/theme.js` (layer-local config, no root `Config.js`).
* Dockable panel shell renders four regions: Left Gate Palette, Main Qubit-Row Circuit Editor, Right Code/AI container, Bottom Inspector container.
* Drag-and-drop gate placement on the qubit-row grid modeled by `Interaction.js` (pure state machine, no DOM).
* `main.js` wires UI leaves; deleting any UI folder requires at most a 2-line diff in `main.js`.
* Zero layering violations: `core/`, `circuit/`, `sim/` never reference `window`/`document`; `gates/` imported only by `main.js`.
* `git status`/`git diff` show only intended files changed (new `src/` UI modules + `test/` UI modules + `docs/Plans/S5.md`).
* No tests asserting hardcoded non-constant outputs.

None import `gates/` directly and none create inter-leaf edges between `debugger/`, `inspector/`, `ai/`.
