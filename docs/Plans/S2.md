## 2. Member Workstreams & Learning Guides

### Member 1: Core Engine & Memory Architect

#### The Learning Anchor (Do This on Paper First)
* Take a 3-qubit state ($n=3$, amplitudes $\alpha_0, \dots, \alpha_7$).
* Write out the binary representation of all 8 indices.
* Apply a Hadamard gate to qubit row 1 ($t=1$, mask $1 \ll 1 = 2$).
* Observe how indices pair up: $(000_2, 010_2)$, $(001_2, 011_2)$, $(100_2, 110_2)$, $(101_2, 111_2)$—or $(0,2), (1,3), (4,6), (5,7)$.
* Notice how the outer block steps by $2 \ll t = 4$, while the inner loop steps through $1 \ll t = 2$ consecutive elements where bit $t=0$. This is the foundation of matrix-free $O(2^n)$ simulation.

#### Implementation Tasks
1. **`src/core/StateVector.js`**:
   * Allocate two parallel `Float64Array(1 << n)` buffers: `re` and `im`.
   * Enforce the initialization invariant: `re[0] = 1.0`, all other elements `0.0`.
   * Implement facade methods: `numQubits()`, `size()`, `getRe(i)`, `getIm(i)`, `probability(i)`, `probabilities()`, `normSquared()`, and `clone()`.
   * Expose internal references `_re` and `_im` strictly for kernel access.
2. **`src/core/kernel.js` (Bare Functions Only)**:
   * **`apply1QubitOp(re, im, n, target, gateFlat, controlMask, antiControlMask)`**:
     * Stride-$2^t$ block iteration using bitwise shifts.
     * Filter pairs using `(i0 & controlMask) === controlMask` and `(i0 & antiControlMask) === 0`.
     * Unroll the canonical 2x2 complex multiplication using the 8-double tuple `g`:
       ```js
       const a0r = re[i0], a0i = im[i0], a1r = re[i1], a1i = im[i1];
       re[i0] = g[0]*a0r - g[1]*a0i + g[2]*a1r - g[3]*a1i;
       im[i0] = g[0]*a0i + g[1]*a0r + g[2]*a1i + g[3]*a1r;
       re[i1] = g[4]*a0r - g[5]*a0i + g[6]*a1r - g[7]*a1i;
       im[i1] = g[4]*a0i + g[5]*a0r + g[6]*a1i + g[7]*a1r;
       ```
   * **`applySwap(re, im, n, q0, q1)`**:
     * Swap amplitudes directly with zero floating-point multiplications.

### Member 2: Gate Physicist & Numerical Foundations

#### The Learning Anchor (Do This on Paper First)
* Calculate the matrix exponential $R_x(\theta) = \exp(-i \frac{\theta}{2} X) = \cos(\frac{\theta}{2}) I - i \sin(\frac{\theta}{2}) X$.
* Evaluate $R_x(\pi)$:
  $$\cos(\pi/2) I - i \sin(\pi/2) X = -i X = \begin{pmatrix} 0 & -i \\ -i & 0 \end{pmatrix}$$
* Confirm that $-i X$ is identical to Pauli $X$ up to an unobservable global phase of $e^{-i\pi/2}$.
* Check unitarity: calculate $G^\dagger G$ and verify that all diagonal entries are $1.0$ and off-diagonals are $0.0$.

#### Implementation Tasks
1. **`src/gates/basis.js`**:
   * Define foundational gates using Sprint 1's `Matrix` class for clear readability ($I, X, Y, Z, H$).
   * Implement a flattening utility: `matrixToFlat8(matrix) -> Float64Array(8)` that flattens `[g00.re, g00.im, g01.re, g01.im, g10.re, g10.im, g11.re, g11.im]`.
   * Flatten all static basis gates once at module initialization.
   * Add phase gates: $S = \begin{pmatrix} 1 & 0 \\ 0 & i \end{pmatrix}$, $T = \begin{pmatrix} 1 & 0 \\ 0 & e^{i\pi/4} \end{pmatrix}$.
2. **`src/gates/param.js`**:
   * Implement parameterized gates as pure functions taking $\theta$ in radians and returning flat 8-tuples directly:
     * `Rx(theta)`: $\cos(\theta/2) I - i \sin(\theta/2) X$
     * `Ry(theta)`: $\cos(\theta/2) I - i \sin(\theta/2) Y$
     * `Rz(theta)`: $\text{diag}(e^{-i\theta/2}, e^{i\theta/2})$
3. **`src/gates/registry.js`**:
   * Build an immutable map resolving string identifiers (`"H"`, `"X"`, `"Rx"`) to their flat tuples or generator functions.
   * Provide a debug assertion verifying unitarity $\lVert G^\dagger G - I\rVert < 10^{-12}$ on registration.

### Member 3: Circuit Model & Pipeline Engineer

#### The Learning Anchor (Do This on Paper First)
* Sketch a 3-qubit circuit with a nested 2-qubit subcircuit "BellBlock" inside column 2.
* Track how column indices work:
  * Top-level canvas column: Column 2.
  * Inside BellBlock: Gate 0 is in Sub-column 0; Gate 1 is in Sub-column 1.
* Trace why execution needs **virtual column boundaries**: if the subcircuit is 2 columns wide, subsequent top-level gates must shift to Virtual Column 4. Otherwise, intermediate debugger steps become out of order.

#### Implementation Tasks
1. **`src/circuit/GateColumn.js` & `src/circuit/Circuit.js`**:
   * `GateColumn`: Passive value class representing a time slice across qubit rows.
   * Assert intra-column disjointness: no two operations in the same column may share target or control qubit rows.
   * `Circuit`: Immutable list of `GateColumn`s with `withColumnAt()`, `withWires()`, and `numQubits`.
2. **`src/circuit/Flatten.js` (The Dual-Layer Pipeline)**:
   * **Layer 1: `flattenCircuit(circuit) -> Instruction[]`**:
     * Recursively inline sub-circuits into a flat 1D array of canonical instruction objects:
       ```js
       { gateId: "H", target: 0, controls: 0, column: 2, virtualColumn: 3, subcircuit: "Bell" }
       ```
   * **Layer 2: `scheduleColumns(instructions) -> ExecutionColumn[]`**:
     * Group flat instructions sharing the same `virtualColumn` into contiguous execution batches for the simulation engine.
3. **`src/circuit/Ascii.js`**:
   * Port Quirk's diagram parser ($\approx 40$ lines) to generate test circuits from text diagrams:
     ```text
     H-X
     --.-
     ```

### Member 4: Verification, CLI & Differential Harness

#### The Learning Anchor (Do This on Paper First)
* Work through the endianness arithmetic proof for $n=3$:
  * **$\text{CNOT}(0 \to 1)$**: Bit 0 is control (mask 1 $\implies$ odd indices $\{1, 3, 5, 7\}$). Bit 1 is target (mask 2 $\implies$ flip bit 1). Swaps $\{1, 3\}$ and $\{5, 7\}$.
  * **$\text{CNOT}(1 \to 0)$**: Bit 1 is control (mask 2 $\implies$ indices $\{2, 3, 6, 7\}$). Bit 0 is target (mask 1 $\implies$ flip bit 0). Swaps $\{2, 3\}$ and $\{6, 7\}$.
* Understanding this difference prevents directional stride bugs where $\text{control} < \text{target}$ behaves differently from $\text{control} > \text{target}$.

#### Implementation Tasks
1. **`src/circuit/Serializer.js`**:
   * Implement `toJson(circuit)` and `fromJson(jsonString)` adhering to the v1 Canonical Schema:
     * Explicit `"format": "simqc-circuit"`, `"version": 1`, `"bitOrder": "little-endian"`.
     * Control lines as explicit objects: `controls: [{ wire: 0, on: true }]`.
2. **`src/cli.js` (Bare Node CLI Runner)**:
   * Accept canonical circuit JSON from `process.stdin`.
   * Parse circuit, run the simulation, and output state vector amplitudes or probabilities to `process.stdout`.
   * Natural architectural guardrail: verify that running `node src/cli.js` without a browser executes cleanly and crashes if any module imports `window` or `document`.
3. **`test/differential.test.js` & `test/kernel.test.js`**:
   * Differential testing: for random circuits up to $n=6$, compare the output of Member 1's $O(2^n)$ pairwise kernel against Sprint 1's $O(4^n)$ `Matrix.tensorProduct` path.
   * Verify IEEE-754 norm preservation after each gate ($\lVert \psi \rVert^2 \in 1.0 \pm 10^{-9}$).
   * Test bidirectional CNOT swapping to permanently guard against big-endian brain slips.

* **Target:** Verify `apply1QubitOp` and `applySwap` using `node --test`.
