Title: Implement Sprint 4 M1.3 (Matrix vs NumPy) and M1.4 (StateVector vs Qiskit) cross-validation

Summary:

Implemented M1.3 and M1.4 of Sprint 4 cross-validation plan:

M1.3 — Matrix algebra cross-validation vs NumPy:
- Created `test/cross-validation/numpy_ref.py` — NumPy reference implementation for `multiply`, `tensorProduct`, `conjugateTranspose`, `isUnitary`, and `frobeniusNormSquared`, emitting JSON results to stdout.
