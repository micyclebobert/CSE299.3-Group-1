Title: Wave 4 Integration — URL codec, drag-and-drop, Debugger UI, AI Builder/I/O Analyzer, PanelModel

Summary:
Wired all Wave 4 submodules into index.html and src/ui/AppController.js:

index.html:
- Removed placeholder DOM; every panel button now performs a real action.
- URL codec: Share button uses app.encodeURL() (URLCodec.encode(app.serialize())) and displays in prompt; on page load, reads #circuit= hash fragment, decodes via app.decodeURL(), and loads via app.deserialize().
- Drag-and-drop: palette click selects a gate entry (AppController._bindPalette now sets _selectedEntry instead of placing); canvas pointerdown → interaction.pick(), pointermove → interaction.drag(), pointerup → interaction.snap() + app.placeGateAt() → app.draw() + renderInspector().
- Debugger UI: Step/Reset/Run buttons call app.step()/app.reset()/app.simulate() → app.draw() + renderInspector(); step counter shows current step / total steps.
- AI Builder: prompt input + "Build circuit" button calls aiBuilder.build(), displays result JSON or error via onChange callback.
- I/O Analyzer: input/output row inputs + "Analyze" button calls ioAnalyzer.analyze(), displays causal chain (affected columns, touched columns, summary, sparse top-k).
- PanelModel: collapse/expand toggle buttons call panelModel.toggle(id) and apply display:none/display:flex to corresponding panels.

src/ui/AppController.js:
- Added encodeURL() → URLCodec.encode(this.serialize()).
- Added decodeURL(urlSafeBase64) → URLCodec.decode() + this.deserialize(), returns {ok, error}.
- Added placeGateAt(column, row, gateName) → builds Gate via Interaction metadata + gateCatalog, calls _setCircuit(), returns {conflict, reason}.
- Added getPointer() → returns this._pointer.
- Added setPointer(x, y) → sets this._pointer = {x, y}.
- Added aiBuilder/ioAnalyzer getters exposing AIBuilderUI/IOAnalyzerUI instances.
- resetCircuit() now creates AIBuilderUI and IOAnalyzerUI instances tied to circuit numQubits.
- Inspector is wired via notify() on every _setCircuit() (already existed, preserved).

src/main.js:
- Added imports and exports for URLCodec, AIBuilderUI, IOAnalyzerUI so index.html can access ai/ and debugger/ modules exclusively via main.js exports (per layering rules).

Tests: All 167 targeted tests pass (0 failures) across test/ui, test/editor, test/ai, test/debugger, test/circuit.
Syntax: node --check --input-type=module passes on both src/ui/AppController.js and src/main.js.
