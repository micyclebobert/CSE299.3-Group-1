Title: Panels, layout, responsiveness, and accessibility UI features

Summary:
Implemented panels, layout, responsiveness, and accessibility features across the editable UI/editor/canvas modules.

src/ui/panels.js:
- Added PanelModel.applyLayoutRects(viewport) returning CSS grid track sizes (gridTemplateColumns/gridTemplateRows) with collapsed panels as 0px tracks so they reclaim space, plus mainW/mainH and the underlying rects.
- Added PanelModel.resizeRegion(id, {width, height}) for panel resizing.
- Added PanelModel.dockRegion(id, position) for docking panels with z-order tracking.
- Added PanelModel.saveLayout()/loadLayout(state) for layout persistence as plain objects (no localStorage in this module).
- getLayoutRects() already returns correct rects for collapsed panels (null / w=0/h=0).

src/canvas/Renderer.js:
- renderCircuit now accepts selectedCell, hoverCell, conflictCells, scale, panX, panY.
- Gate descriptors include selected, hovered, conflict booleans and lineWidth; conflict gates tint red (theme.danger), selected gates use theme.focus stroke, hovered gates use theme.controlHover fill + theme.accent stroke.
- All output coordinates (x, y, w, h, cx, cy, markers, control lines/dots, swap crosses) are scaled by `scale` and offset by panX/panY via transform helpers; rects report totalWidth/totalHeight/scale/panX/panY.

src/editor/Interaction.js:
- Added pointer capture: capturePointer()/releasePointerCapture() and pointerCaptured getter.
- Added drag ghost/preview data: ghostOffset getter (pointer offset from snapped cell top-left).
- Added drop target highlight data: dropTarget getter ({column, row, conflict}) and setDropTargetConflict().

index.html:
- Added ARIA roles to tabs: role="tablist" on tab strips, role="tab" on tabs with aria-selected, aria-controls, tabindex.
- Added role="status" aria-live="polite" status region; aria-live="polite" on ai-output, builder-output, io-output, inspector-content.
- Added <label> elements for all form controls (shots, boundary, qubits, model, prompt, input/output rows, breakpoint column, timeline, share URL, file picker).
- Added canvas role="img", aria-label, title, and fallback content.
- Added responsive CSS breakpoints (@media max-width 900px stacks panels vertically into a single column; max-width 600px tightens padding).
- Added .selected and .drop-target/.ghost CSS classes.

src/ui/browserApp.js:
- Applies panelModel.applyLayoutRects() to #app grid-template-columns/rows on init, resize, breakpoint change, and panel toggle; collapses tracks to let CSS stack panels on narrow viewports.
- Panel toggle buttons reapply layout tracks after panelView toggles visibility.
- Responsive breakpoints via window.matchMedia('(max-width: 900px)').
- Keyboard tab navigation: arrow keys/Home/End move focus between tabs, Enter/Space activate; panel tabs toggle on Enter/Space.
- Visible selected-gate state: palette buttons get .selected class matching app.getSelectedEntry().
- Circuit zoom/pan: CSS transform scale/translate on the canvas, driven by wheel (zoom) and +/-/0 keys (pan offset accumulates under cursor).
- Pointer/touch feedback: #drag-ghost overlay positioned at pointer + ghostOffset during drag; #drop-target overlay at the snapped cell with conflict (red) / valid (green) border.
- Pointer capture via interaction.capturePointer()/releasePointerCapture() on canvas pointerdown/pointerup/pointercancel.
