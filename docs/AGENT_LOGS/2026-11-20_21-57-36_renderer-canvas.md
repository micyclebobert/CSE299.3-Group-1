Title: Sprint 5 M1.3 — Canvas Renderer (pure draw-command emitter)

Summary:
Added src/canvas/Renderer.js: a pure, DOM-free renderer exporting renderCircuit(circuit, theme, { colWidth, colGap, rowHeight, rowGap }). It emits fixed-shape DrawCommand descriptors (gate, line, label, glow) positioned via Layout.columnX/rowY, filled/stroked from theme, with control lines and entanglement glows for controlled gates, plus row labels and column separators. Returns { gates, rows, columns, rects } without mutating the Circuit or importing gates/. Added test/canvas/Renderer.test.js asserting rows/columns, gate positions/colors derived from Layout, control line and glow emission, row labels, column separators, and rects. Full `node --test` suite passes: 572 tests, 563 pass, 0 fail, 9 pre-existing todo.
