Title: URLCodec module (Wave 4, task I-a — deflate-raw + base64url codec)

Summary:
Added src/circuit/URLCodec.js with named exports encode(circuitJson) and decode(urlSafeBase64): canonical v1 JSON is compressed with a zero-dependency RFC 1951 deflate-raw implementation (fixed Huffman + LZ77, 32 KiB window) and encoded as URL-safe base64 without padding ([A-Za-z0-9-_], no '='); decode reverses it. The module is DOM-free and synchronous, runs unmodified in browsers and bare Node.js (TextEncoder/TextDecoder only), has zero module-level mutable state, named exports only, explicit .js imports, const-by-default, no comments/headers, and is 234 lines (under the 400-line cap). Added test/circuit/URLCodec.test.js mirroring Serializer.test.js conventions: 9 tests covering round-trip fidelity, parameterized gates/anti-controls, charset/padding rules, zlib deflate-raw interop, compression ratio, type errors, and empty input.
