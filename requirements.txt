# ============================================================
# SimQC — Browser-Based Quantum Circuit Simulator
# requirements.txt
#
# This project uses NO quantum SDK (no Qiskit/Cirq/PennyLane
# equivalent) and has ZERO runtime JavaScript dependencies.
# The simulation core (complex numbers, state vector, pairwise
# gate kernel, measurement) is implemented entirely from
# scratch in plain JavaScript (ES2023, ECMAScript spec [40]).
#
# ============================================================

# --- Dev dependencies (installed via package.json) ----------
# eslint          ^9.x    static analysis (index-arithmetic and
#                         allocation rules from CONVENTIONS.md)
# prettier        ^3.x    code formatting (4 contributors)

# --- Test runner ---------------------------------------------
# Node.js >= 20 (built-in node --test runner; no package)

# --- External (optional, not npm packages) -------------------
# Ollama (optional): local LLM backend for the AI explainer/
#   builder module. Install from https://github.com/ollama/ollama
#   Only needed if the AI backend is switched to local mode;
#   the default backend is a remote HTTPS API via fetch().
#
# A modern browser (Chrome/Firefox/Edge/Safari — any engine
# with Float64Array + ES2023 support). No other runtime
# requirement; the app is fully client-side.

# ============================================================
# External test dependencies (OPTIONAL — pip install, NOT npm)
# ============================================================
# These are NOT required for `node --test` to pass. They are
# used ONLY for opt-in cross-library differential verification:
#   SimQC bare-function kernels vs. Qiskit/NumPy reference.
# The Qiskit/NumPy differential pipeline consumes SimQC's
# canonical v1 JSON circuit over bare Node `stdin`/`stdout` and
# compares against Qiskit state-vector output.
#
# Install:
#   pip install qiskit numpy
#
# Version guidance:
#   qiskit   >= 1.0   (qiskit-aer for statevector simulation)
#   numpy    >= 1.26
#
# Verification entry point (Python):
#   python scripts/differential_verify.py < simqc_circuit.json
#
# If qiskit/numpy are not installed, `node --test` still passes
# fully — the differential test suite is gated behind import
# availability and silently skips when either package is missing.
